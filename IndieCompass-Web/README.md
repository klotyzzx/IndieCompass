# Инди-компас 2.1 · WebUI

Настольное приложение на **JavaScript + Node.js**, интерфейс на HTML/CSS/JS. Python не нужен. Хостинг не нужен: небольшой сервер слушает только `127.0.0.1` на случайном порту, интерфейс открывается отдельным окном Edge/Chrome. Для поиска нужен доступ к Steam.

## Запуск — без установки npm-пакетов

1. Установите [Node.js 24 LTS](https://nodejs.org/), если его ещё нет.
2. Распакуйте архив в отдельную папку.
3. Дважды нажмите **start.bat**.
4. Оставьте окно запуска открытым; после выхода закройте его. Ctrl+C останавливает локальное приложение.

Используется установленный Microsoft Edge или Google Chrome в режиме отдельного приложения. Если браузер не найден, откройте адрес, напечатанный в окне запуска. Не открывайте `public/index.html` двойным щелчком: для запросов к Steam нужен локальный процесс Node.

Запуск из терминала в папке проекта:

```powershell
node launcher.mjs
```

## Что умеет

- Поиск по названию и постепенная загрузка каталога Steam. Нет списка из четырёх игр и нет фиксированного ограничения каталога в коде.
- Несколько жанров/тегов Steam одновременно (сочетание через «И»), расслабляющая или атмосферная игра, русский язык, Windows/macOS/Linux, одиночная игра/кооператив/мультиплеер, бесплатные/платные/со скидкой, доля положительных отзывов.
- Точный период выхода в Steam с календарями «с» и «по»; границы включены. Сортировка по релизу, отзывам, названию, цене или релевантности.
- Подробная страница: описание, баннер, галерея с увеличением скриншотов, минимальные и рекомендуемые требования по платформам, разработчик, издатель, языки, дата релиза и переход в Steam.
- Избранное, «Не интересно», возврат скрытых игр, сохранение фильтров.
- Тёмный адаптивный интерфейс, клавиатурная навигация, состояния загрузки/ошибки/пустого результата и резервные значки при недоступности изображений.

По умолчанию выбран тег «Инди». Выберите **«Все игры»**, чтобы искать без него. Быстрые подборки заменяют остальные фильтры и оставляют регион. Хорроры и симуляторы в быстрых подборках сочетаются с тегом «Инди». В списке жанров можно выбрать своё сочетание и нажать «Найти игры»; «Все игры» очищает жанры. Избранное открывается без поиска; для подробностей нужен Steam либо ранее загруженный кэш.

## Что значит «все игры из Steam»

Программа обращается к живому каталогу магазина, а не скачивает и не хранит все игры разом. Подгрузка идёт страницами по 50 строк. Недоступные в выбранном регионе, снятые с продажи или не показываемые анонимному пользователю игры могут отсутствовать. Полноту всего ассортимента Steam обещать нельзя.

Официальный [IStoreService/GetAppList](https://partner.steamgames.com/doc/webapi/IStoreService#GetAppList) требует Web API key и возвращает список приложений, а не готовые описания, скриншоты и системные требования. В этой версии обязательный ключ не нужен. Используются публичные, **недокументированные и не гарантированные Valve** запросы магазина:

- `https://store.steampowered.com/search/results/?json=1&category1=998&...` — поиск, фильтры и страницы результатов;
- `https://store.steampowered.com/api/appdetails?appids=...&l=russian&cc=...` — подробности одной игры.

Они могут измениться; парсер и обработка ошибок находятся в `lib/steam.mjs`. Поиск использует английские даты для однозначного разбора, подробности запрашиваются на русском (если перевод есть). Названия игр остаются оригинальными. Рейтинг на карточке — доля положительных отзывов, не оценка приложения.

Период релиза и порог отзывов проверяются по данным загруженных строк. Для верхней даты приложение сначала ищет соответствующую страницу в отсортированном по релизу каталоге. Если Steam не дал точные упорядоченные даты, используется последовательный просмотр с пояснением. Один запрос проверяет не более четырёх страниц; если совпадений пока нет, доступна кнопка **«Продолжить поиск»**. Счётчик Steam относится к основным фильтрам, число показанных карточек — к фактически проверенным совпадениям. Игры без точной даты не включаются в точный период; игры без процента отзывов исключаются при заданном пороге.

Времени прохождения/игровой сессии в этих ответах нет, поэтому фильтра длительности нет. Требования приведены разработчиком: автоматической проверки железа пользователя нет. Баннеры и скриншоты загружаются с CDN Steam; при отсутствии данных показывается понятная заглушка. Цена и доступность зависят от региона.

## Локальное хранение

В обычном запуске: `%APPDATA%\IndieCompassWeb`.

- `preferences.json` — фильтры, скрытые ID и избранные карточки. Запись атомарная.
- `cache` — ответы поиска (15 минут свежести) и подробностей (24 часа). При сетевой ошибке используется имеющаяся копия с явным предупреждением об устаревании. Кэш необязателен; при запуске старые записи и излишек свыше 400 файлов удаляются.

Путь можно переопределить переменной `COMPASS_DATA_DIR`. Изображения отдельно не скачиваются в кэш приложения. Приложение не отправляет предпочтения на сервер разработчика, аккаунтов и телеметрии нет. Поиск и IP-адрес видны Steam, при загрузке картинок — его CDN. В старую Python-версию и её настройки эта версия не записывает.

## Проверено в этой среде

- Node.js 24.20.0; все JS-модули проходят синтаксическую проверку.
- `node --test test/core.test.mjs`: 11 тестов — разбор карточек, цены/отзывы/даты, совместные фильтры, включённые границы периода, переход к старому периоду, пагинация и скрытие, устаревший кэш и сетевые ошибки, атомарное сохранение и повреждённый JSON, HTTP-маршруты и ограничения доступа.
- Headless Chrome с Playwright: карточки, избранное после перезагрузки, скрытие/возврат, дата/язык/режим, подробности, смена платформы требований, галерея, пустая выдача и ошибки. Размеры 1440, 850 и 600 px; горизонтального переполнения и JS-ошибок не было. Использовались контролируемые тестовые ответы, а не выдача живого Steam.
- Реальные запросы к Steam и npm отклонялись сетью среды (`ECONNRESET`). Поэтому **живую интеграцию здесь не подтвердили**. Проверка в обычной сети: запустите приложение, найдите известную игру, откройте подробности, проверьте дату/требования/скриншоты и смену региона.
- Отдельный запуск Edge/Chrome в режиме приложения, установка Electron и сборка EXE здесь не выполнялись. Скринридер также не проверялся.

Тесты логики не требуют зависимостей:

```powershell
node --test test/core.test.mjs
```

## Отдельный EXE через Electron

Предусмотрена оболочка Electron без Node-доступа у страницы: `desktop.cjs`. Она использует тот же локальный backend. Для пользователя такой сборки Node и браузер отдельно не нужны. Путь настроек этой оболочки выбирает Electron (`app.getPath('userData')`), он отличается от обычного запуска.

Команды из папки проекта при доступе к npm:

```powershell
npm install
npm run desktop
npm run dist
```

Сборка появится в `dist`. Версии зависимостей заданы в `package.json`; lock-файл создастся при успешном `npm install`. Сохраните его для повторяемой сборки. **Этот EXE не собран и не проверен.** Перед распространением проверьте запуск на чистой Windows и включите лицензионные уведомления Electron/Chromium/Node.

## Структура

- `launcher.mjs`, `start.bat` — обычный запуск без npm-зависимостей;
- `server.mjs` — локальный HTTP backend, только loopback, проверка Host/Origin и заголовка клиента;
- `lib/steam.mjs` — запросы Steam, очередь, таймауты, нормализация и фильтры;
- `lib/storage.mjs` — предпочтения и дисковый кэш;
- `public/` — интерфейс, никакой удалённый HTML не выполняется;
- `test/core.test.mjs` — воспроизводимые тесты без сети;
- `desktop.cjs`, `package.json` — необязательная Electron-сборка.

Исходники приложения — MIT. Изображения, описания и названия игр принадлежат их правообладателям. Приложение не аффилировано с Valve.

Дополнительно включён `test/ui-check.mjs`: для повторения браузерной проверки нужен Playwright и установленный Chrome. Скриншоты сохраняются во временную папку Windows. `preview-test-ui.png` показывает интерфейс с явно тестовыми карточками, не реальную выдачу Steam.

## Обновление 2.1

Все выпадающие списки заменены на собственные тёмные меню: жанры, атмосфера, цена, отзывы, режим, платформа, сортировка, регион и платформа системных требований. Жанры сохраняются массивом; старый одиночный жанр автоматически подхватывается при запуске. Обводка больше не выходит на соседние подписи. Сердечко и поиск заменены SVG-иконками с проверенным центрированием. Обновлены карточки, кнопки избранного, отметки рейтинга и поиск.

Регрессии проверены в `test/dropdowns-check.mjs` (требует Playwright и Chrome): несколько жанров, сохранение и старые настройки, клавиатура, клик вне меню, списки в подробностях, геометрия иконок, размеры 1440/850/600 px. `preview-dropdown-test.png` — снимок открытого меню с тестовыми карточками.

Для обновления закройте старое приложение, распакуйте новую папку и запустите `start.bat`. Настройки в AppData сохранятся. Если используете собранный EXE, его нужно пересобрать командами выше из новой папки исходников.
